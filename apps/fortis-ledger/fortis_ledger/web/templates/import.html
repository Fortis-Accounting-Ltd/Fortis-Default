Trial balance or account balances

A trial balance or list of classified accounts (CSV or Excel): code, name and either Debit / Credit, one Balance column, or this-year and prior-year columns. Report codes or Xero account types in the file are used if present. Xero's Trial Balance export works as it is.

Importing again replaces the earlier import of the same year, so you can re-import a corrected file.

{{ m.csrf() }}

Fortis workpaper

The year-end workpaper (Excel) with Profit & Loss and Balance Sheet tabs, or an ITR Business tab. Each line is matched to the client's chart by nature, the same way the financial-report-builder skill does it.

{{ m.csrf() }}

Journals

Xero's manual journal import file (*Narration, *Date, *AccountCode, *Amount, positive = debit) or a Date / Reference / Narration / Account / Debit / Credit file. Lines with the same reference (or narration and date) make one journal.

{{ m.csrf() }}

Chart of accounts

A chart exported from Xero (Accounting > Chart of accounts > Export) or another client. New codes are added and existing codes take the file's name, type and report code.
