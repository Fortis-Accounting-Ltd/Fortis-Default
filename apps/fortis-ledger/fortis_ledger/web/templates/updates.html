How updates work
  • An update holds only Fortis Ledger's own code - under 1 MB, not the full installer.
  • GitHub signs each one for the firm's build. Fortis Ledger checks that signature and every file before it installs one, so a changed or look-alike file is refused.
  • It is installed for you alone (no administrator rights needed) and starts the next time Fortis Ledger opens.
  • When an update needs new parts of the program itself, it says so: install that version with the full installer instead.
