Sign in with office email

Everyone signs in with their Fortis Microsoft 365 account. The change log and the "who is editing" notice then show the verified email.

{% if ms.get("required") %}{{ m.icon("check") }} Required on every PC {% elif ms.get("tenant_id") %}Set up - not required yet {% else %}Not set up{% endif %} {% if tested.get("tenant_id") %} Tested: {{ tested.get("email") or user_email }}{% endif %}

How to set it up (about 10 minutes, needs a Microsoft 365 admin)
  1. Open entra.microsoft.com > Applications > App registrations > New registration.
  2. Name: Fortis Ledger. Supported account types: Accounts in this organizational directory only.
  3. Redirect URI: platform Public client/native (mobile & desktop), URI http://localhost. Register.
  4. On the app's Overview page copy the Application (client) ID and Directory (tenant) ID into the boxes below.
  5. Optional: Enterprise applications > Fortis Ledger > Properties > Assignment required = Yes, then add only the people who should use it.

No password or client secret is involved.

Only these email addresses can sign in (blank = any account in your Microsoft 365).

Test the sign-in first - the app only lets you require it after one successful sign-in with these details, so nobody is locked out by a typing mistake.

Xero connection

Lets staff bring a client's chart and year-end balances straight from Xero (read only).

{% if xr.get("client_id") %}{{ m.icon("check") }} Set up{% else %}Not set up{% endif %}

How to set it up (5 minutes, free)
  1. Sign in at developer.xero.com > My Apps > New app.
  2. App name Fortis Ledger, integration type Mobile or desktop app, company URL https://fortisap.com.au.
  3. Redirect URI: http://localhost:{{ form.get('xero_port') or xero_port }}/callback. Create the app.
  4. On the app's Configuration page copy the Client id into the box below. (Desktop apps have no client secret.)

Permissions asked for: {{ xero_scopes }} - reading settings, the chart of accounts and the trial balance only. Xero's free tier allows 5 connected organisations at a time; the app can disconnect each one after it is brought across.

Must match the redirect URI in the Xero app. Leave as {{ xero_port }} unless another program uses it.
